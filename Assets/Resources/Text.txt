# All the words in The UNchosen ONE live here.
#
# One line per piece of text:  key = text
# Change the text after the "=". Leave the key alone, the game looks text up by it.
# \n starts a new line. Lines starting with # are notes and the game skips them.
# Leave a line empty after the "=" and that bit of text disappears.
#
# Put " | " between a few versions of a line and the game picks one at random each time.
# Handy for win and lose lines so they don't repeat. Don't use it on tutorial hints,
# they get redrawn every move and would keep changing.
#
# Anything in {curly braces} gets filled in by the game:
#   {Click} / {click}   "Click" (or "Press X on" if the player rebound the select key)
#   {wait} {restart} {pan}   whatever key the player has for that control
#   {turns}   a turn count like "5 turns" (the words come from word.turn and word.turns below)
#   {level} {turn} {best} {n}   numbers, only where a line's note says so
#
# Save the file and press Play again to see changes.

word.turn = turn
word.turns = turns
back = Back
